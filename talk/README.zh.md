# 技术交流准备包

目标为约30分钟视觉讲述，另用10–15分钟作问答和小修改，适配教授30–45分钟整体交流。材料由AI准备，用户独立练习/现场交流尚未发生。

- DEFENSE.zh.pptx：12页可编辑演示，复用报告图表；图的可编辑SVG与数据在../figures。
- DEFENSE.zh.pdf：实际渲染的阅读版。
- SCRIPT.zh.md：逐页讲稿、时间表、证据和转场。
- CODE_MAP.zh.md：实际函数和行号。
- EXERCISES_AND_SOLUTIONS.zh.md：三项练习、参考解法和预期变化。
- QA_CARDS.zh.md：答辩问答和边界。
- OFFLINE_CHEATSHEET.zh.md：离线代码/公式/命令速查。现场指定环节不用AI/Agent。
- exercise_early75.json、exercise_demo.json：独立CPU helper演示输入与实际结果；不是新模型质量/性能实验。

主表为旧context-v2质量/旧cost-perf-v1性能，v3迁移与本轮24条不混入主质量或速度表。

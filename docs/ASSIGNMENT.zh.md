## 2. 任务 A：Encoder Token Top-K

实现无需训练的视觉 Token 剪枝，支持配置剪枝层列表和各阶段的保留比例。

在指定层的 **Attention 残差连接后、FFN 前**，对 Attention 权重的 head、query 维求平均，得到各 key token 的得分。保留得分最高的 K 个 Token，恢复其原始相对顺序，并将缩短后的序列送入当前层 FFN 及后续 Encoder。

方法参考：[Token 压缩相关论文](https://arxiv.org/abs/2504.01690v2)。实现与实验范围以本任务说明为准。

设 Encoder 共 L 层，层号从 1 开始，完成以下实验：

| 配置 | 剪枝位置 | 保留比例 |
|---|---|---|
| Encoder-Early | 约 L/4 层 | 50% |
| Encoder-Middle | 约 L/2 层 | 50% |
| Encoder-Late | 约 3L/4 层 | 50% |
| Encoder-Multi | 约 L/4、L/2、3L/4 层，依次执行 | 每个阶段保留当前 Token 的 50% |

前三项分别独立运行。多阶段配置在同一次前向过程中依次剪枝，每个阶段根据该层当前序列的 Attention 权重重新打分。请说明层号与 K 的取整规则，报告各阶段实际 Token 数及最终保留比例。如需适配特殊 Token、图像块或后续模块，请说明处理方式。

**报告中必须回答：**

1. Top-K 后，实际存储参数量和 Encoder Token 数分别变化多少？报告参数数量、权重文件大小及逐层 Token 数，并解释这些指标的区别。
2. Encoder 和整个模型的理论 FLOPs 分别变化多少？给出计算公式和各层实际序列长度，说明 Attention、FFN、打分及选择的开销；多阶段配置按实际执行过程计算。
3. 如何证明被丢弃的 Token 没有进入当前层 FFN 和后续 Encoder？提供 forward pre-hook 输入形状，以及 profiler 中相关矩阵乘法的形状与耗时。多阶段配置需覆盖每次剪枝后的计算。
4. 从视觉输入到 LLM 输入，压缩如何传递？报告剪枝前后、Projector 输入输出及最终进入 LLM 的视觉 Token 数，并说明相对基线的变化。

## 4. 任务 C：LLM FFN Skip

自选 3 个 LLM 层，同时跳过这些层的 FFN 计算，无需训练。实现支持配置 Skip 层列表，保持残差路径正确，并说明归一化操作的处理和选层理由。

**报告中必须回答：**

1. FFN Skip 后，模型实际存储参数量变化多少？被跳过的 FFN 包含多少参数？说明统计方法。
2. 理论 FLOPs 变化多少？给出计算公式，说明 prefill、decode、输入长度和生成长度的统计范围。
3. 如何证明指定 FFN 的计算确实没有执行？提交模块调用记录或计数，并结合 profiler 结果说明。
